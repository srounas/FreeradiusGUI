Syslog

Controls where FreeRADIUS sends its logs. Changes are written to the FreeRADIUS config when you click Apply on the Dashboard. The Auth Log page keeps reading its own log file and is not affected.

FreeRADIUS log destination

The syslog facility only applies when the destination is syslog. Writes the log { } block in radiusd.conf.

Authentication events

Sends one structured line per Accept / Reject (user, client, NAS IP, calling station, certificate CN, EAP type, reject reason) to syslog, independent of the log destination above.

Remote syslog server

FreeRADIUS can only write to the local syslog daemon, so forwarding is done by an rsyslog rule that picks up messages from FreeRADIUS and relays them to your collector. Local logging continues as before.
